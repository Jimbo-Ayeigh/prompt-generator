AR · Smart Glasses

Building for AI Glasses

Jetpack Compose Glimmer is a UI toolkit for building augmented reality interfaces on transparent, additive displays. This guide collects the practical code snippets and configuration you need to get an app running and tested.

🕶️

Additive displays

Black renders as transparent — design bright content on dark surfaces.

🎯

Focus navigation

No touchscreen — interactions run through touchpad and focus.

🔠

Large scale

Typography is sized for viewing distance (TitleLarge = 30sp).

1 · Setup & Theming

Glimmer uses a specialized theme optimized for transparent displays. Google Sans Flex is recommended for maximum legibility.

Global theme setup

@Composable
fun MyApp() {
    // Create the specialized typography for AI glasses
    val typography = createGoogleSansFlexTypography()

    GlimmerTheme(typography = typography) {
        // Your app content here
        MainScreen()
    }
}

2 · Basic Components

Buttons

Buttons handle depth and borders automatically for optical displays.

@Composable
fun ButtonExamples() {
    // Standard Button
    Button(onClick = { /* Handle click */ }) {
        Text("Standard Action")
    }

    // Button with Leading Icon
    Button(
        onClick = { /* Handle click */ },
        leadingIcon = { Icon(Icons.Default.Favorite, contentDescription = "Favorite") }
    ) {
        Text("Like")
    }
}

Text & Typography

Text intelligently matches the background surface color, defaulting to high-contrast white.

@Composable
fun TextExamples() {
    Column {
        Text(
            text = "Main Heading",
            style = GlimmerTheme.typography.titleLarge
        )
        Text(
            text = "Body content for glasses",
            style = GlimmerTheme.typography.bodySmall
        )
    }
}

3 · Layout & Containers

Cards

Cards are the primary way to group information and fill the maximum width by default.

@Composable
fun CardExample() {
    Card(
        title = { Text("Event Notification") },
        header = {
            Image(
                painter = painterResource(id = R.drawable.header_image),
                contentDescription = "Header",
                contentScale = ContentScale.FillWidth
            )
        },
        action = {
            Button(onClick = { /* Action */ }) {
                Text("View Details")
            }
        }
    ) {
        Text("You have a new meeting starting in 5 minutes.")
    }
}

Vertical lists

VerticalList is optimized for touchpad / focus-based navigation rather than direct touch.

@Composable
fun ListExample() {
    val items = listOf("Home", "Messages", "Settings", "Help")

    VerticalList(
        title = { TitleChip { Text("Main Menu") } }
    ) {
        items(items) { label ->
            ListItem(onClick = { /* Handle selection */ }) {
                Text(label)
            }
        }
    }
}

4 · Build & Test

Required tools

  • IDE: Android Studio — latest Canary build (required for full XR preview & emulator support).
  • OS: Windows, macOS, or Linux.

Project configuration

SettingValue
minSdk24
compileSdk34 or higher

Dependencies (app/build.gradle.kts)

dependencies {
    // Core XR Runtime
    implementation("androidx.xr.runtime:runtime:1.0.0-alpha14")

    // Glimmer UI Toolkit
    implementation("androidx.xr.glimmer:glimmer:1.0.0-alpha12")
    implementation("androidx.xr.glimmer:glimmer-google-fonts:1.0.0-alpha12")

    // Additional XR support
    implementation("androidx.xr.projected:projected:1.0.0-alpha07")
    implementation("androidx.xr.arcore:arcore:1.0.0-alpha13")
}

Composable previews

  1. Annotate your composable with @Preview.
  2. In the Preview configuration picker, select AI Glasses from the Device drop-down.
  3. Use the Environment icon to simulate lighting (Light, Dark, Busy) and test transparency & contrast.

Android XR Emulator

  1. Open the Device Manager in Android Studio.
  2. Create a new virtual device using the Android XR system image.
  3. Run your app to test focus-based navigation and touchpad interactions.

5 · Key Considerations

Additive displays

Black is 100% transparent on glasses. Test your UI against bright backgrounds to ensure legibility.

No touchscreen

Focus on indirect pointer inputs (touchpad / gestures). Ensure every interactive element is focusable.

Google Sans Flex

Add the glimmer-google-fonts dependency to use the optimized variable font.

Large-scale typography

Type is much larger than mobile to account for viewing distance and glasses resolution.
