# Prompt Architect — AI Glasses app

A native **Android XR** build of Prompt Architect, written with
[Jetpack Compose Glimmer](https://developer.android.com/develop/xr/jetpack-xr-sdk/jetpack-compose-glimmer)
— Google's UI toolkit for AI glasses with transparent, additive displays.

It lets you review your song "blueprints" and the prompt‑chaining technique hands‑free
on glasses, using focus/touchpad navigation instead of a touchscreen.

## Project layout

```
glasses-app/
├── settings.gradle.kts          // modules + repositories
├── build.gradle.kts             // plugin versions
├── gradle.properties
├── gradle/wrapper/…             // wrapper config (jar generated by Studio/Gradle)
└── app/
    ├── build.gradle.kts         // SDK levels + Glimmer/XR dependencies
    └── src/main/
        ├── AndroidManifest.xml
        ├── res/values/…         // app name + minimal platform theme
        └── java/com/promptarchitect/glasses/
            ├── MainActivity.kt      // entry point, GlimmerTheme, navigation
            ├── SongBlueprint.kt     // data model + sample content
            └── Screens.kt           // Home / List / Detail / Chaining screens
```

## Screens

| Screen | Glimmer components | Purpose |
| --- | --- | --- |
| Home | `VerticalList`, `ListItem`, `TitleChip` | Top-level menu (≤ 3 items per view) |
| Song Blueprints | `VerticalList`, `ListItem` | Browse saved blueprints |
| Blueprint detail | `Card` (title + action), `Button` | Review one blueprint + its master prompt |
| Prompt Chaining | `VerticalList`, `ListItem` | Step-by-step chaining technique |

## Build & run

This is a standard Android Studio project. You need the **latest Android Studio Canary**
for full Android XR preview/emulator support (per the Glimmer setup guide).

1. Open the `glasses-app/` folder in Android Studio.
2. Let it sync; Studio generates the Gradle wrapper JAR on first sync. From a terminal you
   can instead run `gradle wrapper` once (a system Gradle ≥ 8.10 is enough to bootstrap).
3. Preview a screen by adding `@Preview` and choosing **AI Glasses** in the device picker,
   **or** run on an **Android XR** emulator image from Device Manager.

### Requirements (from the Glimmer build guide)

- `minSdk` 24, `compileSdk` 34+ (this project uses 35)
- XR runtime + Glimmer toolkit dependencies are declared in `app/build.gradle.kts`

## Notes & caveats

- **Alpha dependencies.** Glimmer/XR libraries (`androidx.xr.*`) are alpha and move fast.
  The versions pinned here match the provided build guide
  (`glimmer:1.0.0-alpha12`, `runtime:1.0.0-alpha14`, …); bump them to the newest alpha if a
  symbol or signature has changed, then re-sync.
- **Not compiled in this environment.** The Android SDK and the alpha Maven artifacts aren't
  available in the container this was authored in, so the project hasn't been compiled here.
  The component usage follows the official Glimmer docs (`VerticalList`/`ListItem` DSL,
  `Card` title/header/action slots, `Button` `leadingIcon`, `GlimmerTheme.typography`), but
  expect to make small adjustments (e.g. the exact import path of
  `createGoogleSansFlexTypography`, or a typography style name) against whatever alpha you
  resolve. These are the kinds of fixes Android Studio will surface immediately on sync.
- The original browser-based companion app still lives at the repository root
  (`index.html`); this `glasses-app/` project is the on-device glasses version.
